````text
(원본 104~104행)
**`MIN_APP_VERSION`(강제 업데이트, 2026-11-02 — 앱 1.0.1 부터 읽는다)** — 이 버전 **미만** 인 앱을 "업데이트해 주세요" 화면으로 막는다. `GET /app/version`(인증 없음, 응답 `{"min_version": "1.0.1"}` 또는 `{"min_version": null}`, `Cache-Control: public, max-age=300`)이 이 값을 알려 주고 앱이 시작할 때와 앱으로 돌아올 때 비교한다. 스토어에 제출한 1.0.0(구글 vc18 · TestFlight 25, 아직 심사 · 공개 대기)은 이 경로를 읽지 않아 막히지 않는다. **2026-11-04 밤 개정: 구글 1.0.0(vc18)은 반려됐고 1.0.1 은 제출하지 않았다 (근거: 결정 기록 16번) — 이 경로를 읽는 첫 공개 버전은 1.0.2 다(§4-20 개정).** 기본은 비어 있어 아무도 막지 않는다. 형식이 `숫자.숫자.숫자` 가 아니면(예: `1.0`, `1.0.1+19`) 서버는 뜨고 로그에 경고(`MIN_APP_VERSION 형식이 올바르지 않아 무시한다`)만 남긴 채 막지 않는다. **고친 빌드가 두 스토어(구글 플레이 · 앱 스토어)에서 모두 공개된 뒤에만 올린다** — 공개되기 전에 올리면 업데이트할 곳이 없는 사람이 앱을 쓸 수 없다. 올리는 법은 새 env 하나를 더하는 `gcloud run services update campus-mate-backend --project=<PROJECT_ID> --region=asia-northeast3 --update-env-vars MIN_APP_VERSION=1.0.1`(새 리비전이 뜬다), 푸는 법은 `--remove-env-vars MIN_APP_VERSION`(앱은 다음 시작 또는 앱으로 돌아올 때 풀린다). 앱이 서버를 못 부르거나(장애 · 3초 시간 초과) 응답이 이상하면 앱은 막지 않는다 — 서버 장애로 앱이 잠기지 않는다. **예시 값 `1.0.1` 로는 아무도 막히지 않는다**(1.0.0 앱은 이 경로를 읽지 않고 1.0.1 앱은 1.0.1 이상이다) — 처음으로 사람을 막는 값은 다음 버전 숫자다(§4-20).
````
