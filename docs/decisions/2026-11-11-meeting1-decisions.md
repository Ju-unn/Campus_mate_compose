## 2. 알려진 한계 · 확인 못 한 것

- 위 사용자 원문은 모두 통합대장이 전달한 것이다. 이 문서 담당은 사용자와 직접 대화하지 않았다.
- 솔라피 키 만료일, 사업자 인증 뒤 하루 한도(1,000), 키 즉시 발급 여부는 대장 전달 값이다. 이 문서 담당은 솔라피 · 클라우드를 조회하지 않았다.
- 아이폰 화면 녹화 방지(3번)는 실기기에서 확인한 결과를 받지 못했다.
- 고정 나가는 IP 에 서버를 묶으면 Supabase · OpenAI · FCM 등 모든 나가는 요청이 NAT 를 지난다. 0% 새 판 시험에서 문자 말고 다른 기능도 도는지 본다(`backend/DEPLOY.md` §4-25).
